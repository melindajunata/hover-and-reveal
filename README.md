# hover-and-reveal

A small personal intro page: hover (or tap, on touch/small screens) one of the scattered emoji to reveal a phrase about melinda in the blank.

Built from [this Figma prototype](https://www.figma.com/design/Zgci90ZNXAMMOO2i4VKvMb/hover-and-reveal).

## Stack

Plain HTML/CSS/JS — no build step, deploys straight to GitHub Pages.

## Local dev

```
node serve.js
```

Then open http://localhost:4173.
